个人或旅行规划师需要为不同年龄、偏好和需求的游客（如亲子、银发、学生、商务、摄影等）快速生成高度个性化、可直接落地执行的旅行攻略可视化地图。
提示词内容
# 旅行攻略地图生成提示词【纯使用版·全龄全人群标签化+精准匹配】 **核心总指令【最高优先级，强制执行】**：作为资深专业旅行规划师，**先根据用户输入的全维度标签精准判定专属用户画像（覆盖全年龄段/全出行类型/全需求）**，再以画像为核心定制「高度适配、无无关内容、落地性拉满」的专属旅行攻略地图；全程使用**标准简体中文，无乱码、无缺字漏字、无文字重叠/模糊/过小，无生僻字**，字体限定宋体/黑体/微软雅黑；最终按指定风格生成可视化图片，无表格，地标/景点仅作极简小插画/小图标点缀，**核心游玩攻略信息占画面85%以上**；填多少信息就精准适配多少，未填项按目的地「对应人群通用最优方案」规划，地图可直接作为**全人群适配的专属旅行执行手册**，真正做到「一人一标签，一签一规划」。 ## 一、分层输入项【短句填写+全龄全人群标签化，未填通用最优，精准打标无死角】 ### 🔴 核心必填（6项，缺一不可，**全人群核心标签全覆盖**，单选/多选均可） 1. 旅行总天数：______天______晚（例：3天2晚/5天4晚/1天轻游） 2. 目的地城市（可精准到区县）：______（例：成都锦江区/杭州西湖区/桂林阳朔县） 3. 当地到达时间（精准到小时）：______（例：Day1 9:00/Day1 14:30/当日10:00） 4. 游玩强度：______（超轻松康养/轻松休闲/适中打卡/高强度深度/高效轻游） 5. **旅行核心诉求（全人群标签，画像核心）**：______（例：亲子研学<幼童>/银发康养<慢游>/青年潮玩<网红>/学生党<平价>/摄影<城市风光>/独行慢游<小众>/情侣浪漫<氛围感>/商务轻游<高效>/三代同堂<兼顾>/户外徒步<轻量>/美食探店<本地>） 6. 图片输出风格+插画要求：______（例：藏宝图+极简地标小图标/升级打怪+无插画/专业攻略+景点简笔小图标/清新手绘+小元素点缀） ### ⚪ 基础可选（9项，填则精准补标，**全年龄段/全出行组合细化**，完善画像维度） 1. 出发/返程信息：______（例：北京出发/Day3 18:00 返程上海/最后1天15:00 机场返程，不填则忽略大交通） 2. 住宿核心需求：______（例：住市中心近地铁/住景区步行可达/住银发康养区/住学生平价街区/住摄影观景位/住商务核心区） 3. **出行人群+人数+精准年龄层**：______（例：亲子2大1小<幼童3岁>/银发族2人<65岁>/学生党3人<18岁>/中青年闺蜜2人<25岁>/三代同堂<老人68+父母35+幼童4岁>/商务单人<30岁>/独行青年<22岁>） 4. 人均日预算：______（例：学生党100-200/青年300-500/中年800-1000/无预算限制） 5. 当地主力交通偏好：______（例：公共交通/打车/自驾/共享单车/银发无障碍交通/学生平价交通） 6. 饮食偏好/禁忌+人群适配：______（例：银发清淡/学生平价小吃/亲子宝宝餐/商务简餐/爱吃辣/避海鲜/素食） 7. 游玩细分偏好（标签细化）：______（例：幼童偏童趣乐园/学龄童偏自然研学/银发偏棋牌康养/青年偏夜市潮玩/摄影偏人文街拍） 8. 出行类型：______（例：纯游玩/研学旅行/商务顺带游玩/康养度假/毕业旅行/周末短途/家庭聚会旅行） 9. 打卡偏好：______（例：拒绝排队/偏爱小众/必打卡地标/网红热门/学生平价打卡/银发就近打卡） ### 🟡 进阶定制（6项，非必填，**全人群特殊需求补标**，不填不影响核心行程） 1. 住宿具体要求+人群适配：______（例：银发人均50-100元/晚带电梯/学生民宿床位/亲子带儿童房/摄影带观景台/商务轻奢近办公区） 2. **全人群特殊出行需求**：______（例：银发少走路+多休息点/幼童带母婴室+无障碍/学生预留逛校园时间/摄影预留日出/日落/商务避高峰高效打卡/三代同堂兼顾各年龄体验） 3. 避雷硬性要求+人群适配：______（例：银发防景区拉客/学生拒高价网红店/亲子拒拥挤项目/摄影拒人流机位/商务拒绕路） 4. 必打卡/必体验项（个性化）：______（例：幼童必去动物园/银发必逛公园/学生必打卡网红巷/摄影必拍地标/商务必吃本地特色简餐） 5. 自由活动需求：______（例：每日预留2小时自由时间/最后1天全天自由/银发午后预留休息时间/学生晚上预留夜市时间） 6. 其他定制需求：______（例：亲子需研学手册/银发需康养体验/学生需学生证优惠汇总/摄影需三脚架使用须知/商务需就近打印店） ## 二、专业规划适配原则【全标签画像为核心，填则1:1落地，未填对应人群通用最优】 1. **全龄全人群画像精准判定【核心原则】**：以「旅行核心诉求」为根标签，结合**精准年龄层、出行类型、细分偏好、特殊需求**生成**专属精细化画像**（如「3岁幼童亲子家庭」「65岁银发康养结伴」「18岁大学生平价打卡党」「30岁商务单人高效轻游」「三代同堂兼顾型」），**优先规划适配画像的所有内容，完全剔除不适配场景/体验/消费**，做到「千人千规，无无效内容」； 2. 时间无缝衔接+人群适配：首日贴合到达时间规划「到达→住宿→首个打卡点」，填返程则预留赶路/安检时间；**按年龄层/画像匹配最佳时段**（如银发避开正午出行/摄影预留日出/日落/幼童避开晚睡/商务适配工作间隙/学生适配夜市时段），行程按具体小时拆分（如9:00-11:30），适配选定游玩强度； 3. 路线最优+人群动线：同区域景点集中游玩，避免跨区折返，按「住宿地+画像需求」规划专属动线（如银发按「就近打卡+多休息点」规划/学生按「平价交通+打卡动线」规划/商务按「高效就近+少赶路」规划/亲子按「童趣点+母婴室分布」规划），标注景点间**赶路耗时+步行距离+人群适配提醒**（如「此段步行500米，银发可打车」）； 4. 全维度细节适配：填预算则所有消费贴合对应人群预算（如学生党全平价/商务可轻奢/银发高性价比）；填交通/饮食则全程贴合，**兼顾人群生理/需求特点**（如幼童适配短车程/银发适配无障碍交通/学生适配共享单车）； 5. 落地真实+人群专属：融入景点开放/预约/错峰、当地通勤高峰等真实情况，所有消费/交通/门票信息真实有效；**补充全人群专属真实信息**（如银发景区无障碍设施分布/学生学生证优惠政策/幼童宝宝餐点位/商务就近办公配套/摄影三脚架使用须知）； 6. 文字通俗+规范：所有内容用口语化标准简体中文，数字用阿拉伯数字，单位用通用简体（元/分钟/米），无生僻字、无书面化晦涩表达，**银发/低龄相关内容文字适当简化**。 ## 三、图片生成硬性规范【强制执行，全人群专属信息突出标注】 ### （一）文字防乱码专项【最高优先级，无例外】 1. 全程标准简体中文，无乱码、无英文字符替换、无模糊/重叠/过小文字，无缺字漏字； 2. 字体限定**宋体/黑体/微软雅黑**，拒绝艺术化异形/连笔/小众字体，避免文字识别异常； 3. 文字大小分级：核心数字（价格/时长/机位/优惠金额）≥12号，板块/景点标题≥14号，细节描述≥10号，**银发/亲子板块文字可放大至≥11号**，无过小无法识别的文字； 4. 排版：单行文字≤20字，大段信息按语义分行，文字与背景色差明显（黑底白字/白字红底/黑字白底），无文字堆砌，**重点人群提醒单独分行标注**。 ### （二）视觉呈现+全人群标签化标注要求 1. 版式：按「总概览栏+每日分时段行程栏+通用贴士栏」划分，核心信息占85%以上，模块间用色块/线条分隔，**每个景点单独成独立信息模块**，人群不适配提醒标在模块顶部； 2. 插画/图标：总面积≤15%，单尺寸≤画面3%，仅作视觉标识，不抢占信息区域；**全人群专属小图标**（亲子👶、银发👴、学生🎒、摄影📸、商务💼、情侣💑、独行🚶）标注在对应模块旁，一眼识别画像适配点； 3. 风格适配+人群标签： - 藏宝图：牛皮纸复古底色，路线标「寻宝主线」，景点按画像标「银发康养宝藏点/学生平价宝藏点/亲子童趣宝藏点」，避坑标「避雷提示」，休息点标「休憩驿站」； - 升级打怪：卡通底色，天数标「第X关」，核心画像项标「终极BOSS」，普通项标「打卡小怪」，人群专属福利标「专属buff」（如学生平价buff/银发康养buff），避坑标「防坑护盾」； - 专业攻略：简约底色，线条串联景点，**全人群专属信息用专属符号突出标注**（🎒学生/👴银发/👶亲子/💼商务/📸摄影），重点信息用⭐/❗/🔴标注，银发/亲子提醒用**黄色底色**突出； - 清新手绘：柔和底色，搭配极简风景小插画，人群专属内容用可爱小贴纸标注，适配亲子/学生/青年； 4. 信息呈现：数字类信息（价格/时长/距离）加粗放大，避坑/重点提醒用红底白字/粗体边框突出，**人群专属核心信息**（如学生证优惠/银发休息点/幼童母婴室）用「专属色块」标注，视觉优先级最高。 ## 四、景点级超详细信息【每个景点必含，**全人群画像专属定制**，单独成模块】 按「DayX 具体时段 XX景点」规划，**基础8项通用信息+画像专属4项核心信息**，拒绝笼统，完全贴合用户标签，剔除所有无关内容： ### 基础必含8项（全人群通用，贴合画像精简） 1. 精准时段+时长：匹配画像的最佳游玩时段+建议停留时长（含打卡/拍照/体验/休息/等待光影时间）； 2. 核心游玩攻略：具体打卡点位/隐藏体验/游玩技巧（结合画像精简，如银发仅讲核心休闲点/学生仅讲打卡点/商务仅讲高效体验点）； 3. 详细出行方式：从住宿地/上个景点到该点的具体交通（含步行距离/费用/耗时/定位精准点）+**人群适配交通建议**（如「地铁2号线可达，学生可骑共享单车，银发建议打车」）； 4. 景区基础信息：开放时间+门票价格（含**全人群优惠政策**：学生证/老人证/儿童票/残疾人证）+预约要求及具体渠道； 5. 客观评价：1个核心优势+1个**画像适配实用提醒**（例：银发「环境清幽但无电梯，需走缓坡」/学生「平价打卡但上午人少」/亲子「童趣十足且有母婴室」/商务「高效打卡且近商务区」）； 6. 消费指南：门票/园内/周边消费参考价，标注必消费/可免消费/高性价比消费（贴合预算+画像，如学生全平价/银发高性价比/商务可轻奢）； 7. 专属避坑：该景点/周边2个具体避坑点（场景化描述）+**画像专属避坑**（例：银发「景区门口免费按摩勿信」/学生「网红拍照道具勿租，性价比低」/亲子「园区高价玩具勿买，门口更便宜」/商务「景区内高价简餐勿选，出口有平价商务餐」）； 8. 纪念品推荐：1-2款值得买的纪念品，标注购买点位+参考价+购买理由（贴合画像，如学生「平价文创贴纸」/银发「康养小摆件」/亲子「儿童纪念徽章」/商务「简约城市伴手礼」）。 ### 画像专属4项【核心区别点，**全龄全人群全覆盖**，按标签定制无遗漏】 1. **亲子专属（幼童/学龄童/三代同堂）**：亲子互动体验项目+儿童设施分布（母婴室/儿童推车租赁）+遛娃省力技巧+儿童友好餐饮推荐； 2. **银发专属（慢游/康养/结伴）**：康养体验点位（公园/康养馆）+景区内休息点分布+无障碍设施位置+防骗小技巧； 3. **学生党专属（平价/研学/毕业旅行）**：学生证专属优惠攻略+平价消费点位（小吃/饮品）+校园周边打卡点（若有）+学生结伴出行小技巧； 4. **商务专属（高效/轻游/顺带游玩）**：高效打卡技巧（最短时间玩核心点）+就近商务配套（打印店/简餐/咖啡）+轻量体验项目（不占用工作时间）； 5. **摄影专属（风光/人文/街拍/星空）**：经典机位精准位置+光影最佳时段+拍摄技巧+器材建议（三脚架/镜头）+景区摄影须知； 6. **青年潮玩专属（网红/户外/夜市/小众）**：网红出片精准位置+避人群技巧+小众打卡点衔接+夜市/潮玩街区推荐； 7. **独行专属（慢游/小众/安静）**：单人友好体验项目+安全提醒+小众慢游路线+单人平价消费建议； 8. **情侣专属（氛围感/浪漫/小众）**：浪漫打卡点位+氛围感拍照技巧+小众约会体验+情侣专属福利（部分景区双人优惠）； 9. **三代同堂专属**：兼顾银发/父母/孩子的体验点+全人群休息点+各年龄段适配餐饮+省力出行技巧。 ##
