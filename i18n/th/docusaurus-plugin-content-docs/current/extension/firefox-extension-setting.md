# การตั้งค่าส่วนขยาย Firefox

ตั้งแต่ v4.4.0 เวอร์ชัน Firefox เหมือนกับเวอร์ชัน Chrome คือมีโหมดแสดงผลสามแบบ — **แถบด้านข้าง ป๊อปอัป และหน้าต่างแยก** — และคลัง prompt ถูกรวมมาในตัวส่วนขยาย

ส่วนขยายขอเพียงสิทธิ์ `storage` เท่านั้น ไม่อ่านและไม่แก้ไขหน้าเว็บที่คุณเปิด จึง**ไม่ต้องอนุญาตทีละเว็บไซต์อีกต่อไป**

> เวอร์ชันเก่า (v4.3 และก่อนหน้า) ใช้ content script แทรกแถบด้านข้างลงในหน้า ChatGPT จึงต้องคลิกขวาที่ไอคอนแล้วเลือก "Always allow on \*\*\*" กลไกนี้ถูกนำออกแล้ว หลังอัปเดตข้ามขั้นตอนนี้ได้เลย

## คีย์ลัด

- `Alt + Shift + S`: เปิดส่วนขยายตามโหมดแสดงผลปัจจุบัน
- `Alt + Shift + D`: เปิด/ปิดแถบด้านข้างเนทีฟของ Firefox

ปรับได้ที่ `about:addons` → ไอคอนฟันเฟือง → "Manage Extension Shortcuts"

## หน้าตั้งค่า

ปักหมุด AI Short ไว้บนแถบเครื่องมือ Firefox แล้วเปิด "Options" ของ AI Short จากหน้าส่วนขยาย เพื่อสลับภาษา โหมดแสดงผล และโหมดมืด

ความหมายของแต่ละการตั้งค่าดูได้ใน[คู่มือการใช้งาน](./usage)
