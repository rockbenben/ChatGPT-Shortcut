# Настройки расширения Firefox

Начиная с версии v4.4.0 сборка для Firefox совпадает с версией для Chrome: те же три режима отображения — **боковая панель, всплывающее окно и отдельное окно**, а библиотека промптов входит в состав расширения.

Расширение запрашивает только разрешение `storage`: оно не читает и не изменяет посещаемые вами страницы, поэтому **разрешение для каждого сайта больше не требуется**.

> В старых версиях (v4.3 и ранее) боковая панель встраивалась в страницу ChatGPT через content script, из-за чего приходилось нажимать правой кнопкой на значок и выбирать «Всегда разрешать на \*\*\*». Этот механизм удалён — после обновления шаг можно пропустить.

## Горячие клавиши

- `Alt + Shift + S` — открыть расширение в текущем режиме отображения
- `Alt + Shift + D` — показать или скрыть нативную боковую панель Firefox

Изменить их можно в `about:addons` → значок шестерёнки → «Управление горячими клавишами расширений».

## Страница настроек

Закрепите AI Short на панели инструментов Firefox, затем откройте «Настройки» (Options) расширения на странице дополнений, чтобы сменить язык, режим отображения и тёмную тему.

Что делает каждая настройка, описано в [руководстве по использованию](./usage).
