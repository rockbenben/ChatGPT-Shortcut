# Firefox 拡張機能の設定

Firefox 版は v4.4.0 以降、Chrome 版と同等になりました。**サイドバー・ポップアップ・独立ウィンドウ**の 3 つの表示モードを備え、プロンプトライブラリは拡張機能内にローカル同梱されています。

拡張機能が要求する権限は `storage` のみで、閲覧中のページを読み取ることも変更することもありません。そのため、**サイトごとの許可は不要**です。

> 旧バージョン（v4.3 以前）はコンテンツスクリプトで ChatGPT のページにサイドバーを挿入していたため、アイコンを右クリックして「このサイトでの実行を常に許可」を選ぶ必要がありました。新バージョンではこの仕組みは廃止されているため、アップデート後はこの手順を省略できます。

## ショートカット

- `Alt + Shift + S`：現在の表示モードで拡張機能を開く
- `Alt + Shift + D`：Firefox のネイティブサイドバーを開閉

`about:addons` → 右上の歯車 →「拡張機能のショートカットを管理」でカスタマイズできます。

## 設定画面

Firefox のツールバーに AI Short をピン留めし、拡張機能ページから AI Short の「オプション」（Options）を開くと、言語・表示モード・ダークモードを切り替えられます。

各設定の詳細は[拡張機能の使い方](./usage)をご覧ください。
